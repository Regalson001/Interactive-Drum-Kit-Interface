## 📌 Project Overview

The **Interactive Drum Kit Interface** is a responsive web-based electronic drum machine designed to recreate the experience of playing a digital drum set directly in a browser.

The project combines modern front-end development techniques with interactive audio functionality to create an engaging and visually appealing musical interface.

Users can interact with individual drum pads, explore different percussion sounds, and control audio settings through a clean and responsive interface.

This project demonstrates practical skills in HTML5, CSS3, JavaScript, event handling, responsive design, and browser-based audio development.

## ✨ Features

- **Interactive Drum Pads:** A collection of digital percussion pads representing different drum instruments.
- **Multiple Drum Categories:** Kick, Snare, Hi-Hat, Tom, and Cymbal.
- **Audio Interaction:** JavaScript-powered sound generation and playback.
- **Keyboard Controls:** Keyboard-triggered drum interactions where supported by the implementation.
- **Volume Control:** Adjust the audio output using the volume slider.
- **Mute Functionality:** Toggle audio output on and off.
- **Visual Feedback:** Interactive hover, focus, and active states.
- **Responsive Layout:** Adaptable interface for desktop, tablet, and mobile screens.
- **Modern UI Design:** Organized layout, clear labels, and distinct pad categories.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Regalson001/Interactive-Drum-Kit-Interface.git
```

### 2. Navigate to the Project Folder

```bash
cd Interactive-Drum-Kit-Interface
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the Application

Open `index.html` in your browser.

You can also use the Visual Studio Code Live Server extension to preview the application while developing.

## 🎮 How to Use

1. Open the application in your browser.
2. Select a drum pad to trigger its corresponding sound.
3. Use the supported keyboard shortcuts if available.
4. Adjust the volume slider to control audio output.
5. Use the mute control to toggle sound.
6. Enjoy experimenting with different percussion sounds.
